# BigBasket Category Diagnostic

A data-analysis project that studies BigBasket-style product, customer, order, and category revenue data using Python, SQLite, SQL, CSV, Excel, and Tableau.

## Project Objective

The objective of this project is to:

- Generate realistic BigBasket order and product data
- Analyze category-wise revenue and order performance
- Practice SQL joins, aggregation, filtering, and verification
- Prepare revenue data for Excel and Tableau visualization

## Technologies Used

- Python
- SQLite
- SQL
- CSV
- Microsoft Excel
- Tableau

## Repository Files

- `generate_data.py` - Generates the SQLite database and CSV datasets
- `bigbasket_capstone.db` - SQLite database generated by the Python script
- `orders_raw.csv` - Raw order-level dataset
- `products.csv` - Product master dataset
- `02_aggregation_joins.sql` - SQL queries using joins, aggregation, GROUP BY, and HAVING
- `verify.sql` - Queries used to verify database record counts
- `monthly_category_revenue.csv` - Monthly category revenue data
- `monthly_category_revenue.xlsx` - Excel revenue analysis file
- `monthly categary revenue dashboard.twb` - Tableau workbook for revenue visualization

## Database Details

The Python script creates a SQLite database named:

`bigbasket_capstone.db`

The database contains these tables:

- `products`
- `customers`
- `orders`
- `category_targets`

The generated dataset includes:

- 31 products
- 50 customers
- 500 orders
- 6 category targets
